# 使用指南

> 本技能为跨平台 Agent Skill，已上架 [SkillsMP](https://skillsmp.com) 和 [腾讯 SkillHub](https://skillhub.cn)。
> 在支持 Agent Skills 的 AI 工具中直接描述你的医疗健康需求即可触发。

## 🩺 症状分析

**示例输入：**
```
我最近三天一直头痛，伴有轻微发热，喉咙痛，流鼻涕。之前有过敏性鼻炎病史。
```

**输出：** 结构化症状分析报告，包括可能的诊断、建议检查等。

## 💊 药物查询

**示例输入：**
```
查询阿莫西林，与布洛芬有相互作用吗？
```

**输出：** 药物信息 + 相互作用检查结果。

## 📚 文献检索

**示例输入：**
```
搜索 PubMed 关于 COVID-19 长期影响的 recent 文献
```

**输出：** 最多 5 篇相关文献的结构化摘要。

## 📖 术语解释

**示例输入：**
```
解释什么是"心肌梗死"和"心绞痛"的区别
```

**输出：** 术语的中英文定义、临床意义和相关术语。

## ✍️ 健康科普

**示例输入：**
```
写一篇关于高血压预防的健康科普文章，适合中老年读者
```

**输出：** 结构化科普文章，含关键要点和参考资料。

## 📋 报告解读

**示例输入：**
```
帮我解读这份血常规报告：
WBC: 11.2 ×10^9/L
RBC: 5.1 ×10^12/L
Hb: 155 g/L
PLT: 250 ×10^9/L
NEUT%: 78.5%
LYMPH%: 15.2%
```

**输出：** 结构化检验报告解读。

## 💡 高级技巧

- **组合使用**：可以同时问多个问题，如"我头痛和发烧，帮我查一下相关的文献"
- **指定格式**：可以要求输出特定格式，如"用表格形式展示"
- **追问**：在获得回答后可以继续追问更多细节
