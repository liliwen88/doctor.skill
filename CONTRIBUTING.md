## 贡献指南

感谢你考虑为 `doctor.skill` 做出贡献！我们欢迎任何形式的贡献，包括但不限于：

### 📋 贡献类型

- **🐛 报告 Bug** — 通过 GitHub Issues 提交
- **💡 功能建议** — 通过 GitHub Issues 提交新功能想法
- **📝 文档改进** — 修正拼写错误、完善文档内容
- **🌐 翻译** — 帮助翻译文档到更多语言
- **⚕️ 医学知识** — 更新药物信息、疾病知识等参考文档
- **💻 代码** — 改进 API 脚本、添加新功能

### 🚀 开始贡献

1. **Fork** 本仓库
2. 创建你的特性分支 (`git checkout -b feature/amazing-feature`)
3. 提交你的更改 (`git commit -m 'feat: add amazing feature'`)
4. 推送到分支 (`git push origin feature/amazing-feature`)
5. 创建一个 **Pull Request**

### ✅ 代码规范

- 使用 Python 编写 API 脚本
- 遵循 [Conventional Commits](https://www.conventionalcommits.org/) 规范
- 保持 Markdown 文件格式整洁（请运行 `npm run lint` 检查）
- 所有医学参考信息必须标注来源

### ⚕️ 医学内容贡献特别说明

由于医疗信息的敏感性，贡献医学相关内容时请特别注意：

1. 所有医学声明必须附有可靠来源（PubMed、WHO、CDC、NMPA 等）
2. 不要包含未经证实的治疗方案或药物推荐
3. 语言应当准确、谨慎，避免绝对化表述
4. 始终包含适当的免责声明

## Contributing

We love your input! We want to make contributing to `doctor.skill` as easy and transparent as possible.

### Types of Contributions

- **🐛 Bug Reports** — File via GitHub Issues
- **💡 Feature Requests** — Suggest new features via GitHub Issues
- **📝 Documentation** — Fix typos, improve docs
- **🌐 Translations** — Help translate documentation
- **⚕️ Medical Knowledge** — Update drug info, disease references
- **💻 Code** — Improve API scripts, add features

### Getting Started

1. **Fork** the repository
2. Create your feature branch (`git checkout -b feature/amazing-feature`)
3. Commit your changes (`git commit -m 'feat: add amazing feature'`)
4. Push to the branch (`git push origin feature/amazing-feature`)
5. Open a **Pull Request**

### Code Standards

- Write API scripts in Python
- Follow [Conventional Commits](https://www.conventionalcommits.org/)
- Run `npm run lint` to check Markdown formatting
- All medical references must cite sources

### Medical Content Guidelines

1. All medical claims must cite reliable sources (PubMed, WHO, CDC, NMPA, etc.)
2. Do not include unverified treatments or drug recommendations
3. Use precise, cautious language — avoid absolutes
4. Always include appropriate disclaimers
